# 検索負荷観測

domcontentloaded後0msの観測です。HTTP 200やhref候補は検索成功・完全SERP到達・精度を証明しません。検索試行は予約した枠数です。QPSはブラウザの試行開始時刻から算出し、サーバー到達数を保証しません。main_documentはリダイレクトや通信失敗も含む台帳の記録数です。

設定QPSは開始間隔の上限で、ブラウザ遷移・証拠保存に時間がかかると実測QPSが下がります。初回は全サイトを一巡してから反復したため、最初のステージの平均にはその待機時間も含みます。今回の最大試行開始QPSは0.473で、1QPSでの安定性は未検証です。

main_document記録数にはsubframe navigationも含まれ、主画面の検索要求数とは一致しません。Bingの中断した46試行目ではmeasurementのmain_record参照が欠けていますが、台帳11466をsite keyとsession_sequenceで照合できました。HTTP値は補完せず、[最終監査](state-audit-summary.json)へ警告を残しています。

先行runと同じ出口IPを継続使用しています。先行試行を含むため、このrun内の回数を新規IPの制限閾値として扱えません。累計も検索試行の予約数で、サーバーへの到達数ではありません。

Brave Searchは今回15試行目でHTTP 429。同じIPで先行2試行があり、累計17試行時点の観測です。

Yahoo! JAPANは今回62試行目でHTTP 429。同じIPで先行32試行があり、累計94試行時点の観測です。

各サイトの2回目以降に3分の時間枠を配分し、上限100試行または拒否で終了しました。時間配分による親側停止はサービス拒否と分けています。
